# Basket Lover

App para entrenadores de baloncesto: calendario, sesiones, pizarra, scouting, cuadrante FBM y estadística en directo.

Se abre en https://daviddeteresablanco-arch.github.io/basket-lover/ y se instala desde el navegador («Añadir a pantalla de inicio»).
Los datos se comparten entre los entrenadores de un grupo a través de Supabase (`supabase.sql` crea las tablas y las reglas de acceso).
